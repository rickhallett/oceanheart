Start with the operating problem. Finish with a system somebody else can own.

  1. 01

    Find the real constraint

    Walk through the current process with the person doing it. Name the trigger, decisions, exceptions, owner, and present cost.

  2. 02

    Choose the smallest useful change

    Decide whether the answer is automation, custom software, AI assistance, or a simpler process. Set a baseline before building.

  3. 03

    Build for failure as well as success

    Test with safe data, make errors visible, preserve human approval for consequential actions, and give failed work somewhere to go.

  4. 04

    Measure and hand over

    Run the workflow against real work, monitor what breaks, document recovery, and leave the owner able to operate it without depending on me.
