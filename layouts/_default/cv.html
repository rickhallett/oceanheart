Full-stack engineer with a focus on AI-augmented development. I build application code and the verification infrastructure that makes it safe for agents to contribute: adversarial review pipelines, structured evaluation, operator telemetry. What I built

Everything below is public. The git logs are the proof.

Sortie
Async adversarial multi-model code review system. Runs a configurable roster of LLMs (Claude, Codex, Gemini) against a worker's diff in parallel, synthesises findings through a 4th-model debrief with convergence analysis, triages by severity, and gates worktree merges. Built after surveying 40+ existing tools and 30+ research papers — designed to fill a specific gap none of them cover. 106 tests, Python, single runtime dependency. Project page →
Pidgeon · Pidgeon Swarm
Same spec, two processes. A carrier-agnostic shipping rate integration built twice: once with outside-in TDD and 48 cross-model adversarial reviews (86 commits, 161 tests, 18 hours), once with design-first parallel agent execution (17 commits, 55 tests, 1 hour). Machine-queryable decision log, self-critical retrospective, direct comparison of iterative verification vs upfront design. Case study →
The Gauntlet · Darkcat
Multi-model adversarial review pipeline enforced as a git pre-commit hook. Claude, Codex, and Gemini independently red-team every code change. Cryptographic attestations tied to git tree hashes — if staged content changes after review, the attestation goes stale and the commit is blocked. Pilot run across a 147-commit project produced 31 findings from 3 models — 74% caught by only one model, 0 false positives. That complementarity data is what motivated building Sortie as the generalised, configurable version.
Tells
Field taxonomy of LLM anti-patterns caught in the wild: epistemic theatre, paper guardrails, analytical lullabies, sycophantic drift. 60+ entries, each with detection heuristics, severity grading, and the story of how it was caught. Includes programmatic detectors that annotate text in real time.
