## Practical takeaway

Lead with Product Reliability Engineer. The fit is strongest where Normal needs AI-assisted validation, regression tooling, failure-mode analysis, traceability, and human-in-the-loop quality systems. Product Engineer is worth raising as an adjacent track because the CV also shows full-stack product work, technical UX, APIs, and AI workflow prototypes.

Do not over-sell semiconductor domain experience. Sell the transferable pattern instead: ambiguous specification or user behavior -> structured tests and validators -> traceable outputs -> human review -> reliable product workflow.
