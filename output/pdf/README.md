# CV output files

Two kinds of files live here:

- `richard-hallett-<role>.pdf`: role-named internal build artifacts. They name
  the role, so they are for local reference only. Do not upload them to an
  application portal; a role in the filename signals cross-function targeting.
- `upload/`: the role-neutral files to actually send to applications and ATS
  systems. Each lane uses a different personal-name variant, so no filename
  reveals the role or a version number.

Read `upload/FILE-NAME-MAP.md` to choose the right file. It maps each name
variant to its role and source, and is regenerated by the build so it cannot
drift.

The source files live in `career/cv/`. Rebuild everything (PDFs, the upload
copies, and the map) with `uv run exports/build-cv.py`; never edit a generated
PDF directly.
