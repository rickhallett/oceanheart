## Read this before uploading a CV

Upload the PDFs in this folder (`output/pdf/upload/`) to job applications and ATS systems. Do not upload the role-named files in `output/pdf/`: an ATS shows the filename to the recruiter, and a role in the name (or a number) reads as scattergun applying.

Each lane therefore uses a different personal-name variant. The role a file targets is recorded only in the table below, never in the filename. Do not rename these files to make them look consistent.
